Don’t Block My Way to Get a Job

An Intelligent Layout Assessment for Career Fairs

Crowd Simulation Machine Learning Optimization
Year 2025
Category Machine Learning, Role-Based Agent Simulation
Toolkit Python, LunchBox, Grasshopper
Instructor Jimmy Cheng

High-density events like career fairs often suffer from severe congestion and inefficient circulation. This project introduces a machine learning–driven spatial design tool that predicts crowd dynamics in real time. By training a Neural Network Regression model on thousands of agent-based simulations, the system functions as a surrogate model, bypassing time-consuming physics-based calculations to provide near-instant feedback. Designers can input booth layouts and obstacle configurations to visualize congestion risks immediately, enabling data-driven spatial optimization for improved accessibility and flow.

First, I define the core agent behaviors within the simulation. Each agent responds to others through separation, seeks assigned targets, and avoids obstacles, enabling realistic crowd movement patterns. The simulation advances through a time-stepping process controlled by a trigger input. Linked to a Grasshopper Timer, this input sends a rhythmic series of boolean pulses to the Python script. With each pulse, the system executes the agents' update functions, calculating perception, decision-making, and locomotion—to create a fluid, real-time visualization of crowd dynamics.

Second, I use Galapagos, an evolutionary solver, to explore a wide range of spatial configurations. By running iterative optimization, Galapagos evaluates each candidate layout based on congestion metrics derived from the agent-based simulation. Through repeated mutation, selection, and refinement, the solver gradually converges toward floor plan arrangements that minimize crowding and maximize circulation efficiency.

During this iterative process, the performance output of every tested layout, regardless of whether it is optimal or not, is systematically recorded. These accumulated results form a comprehensive dataset that captures the relationship between spatial configuration and crowd behavior, serving as the foundation for subsequent neural network model training.

Finally, I train a Neural Network model using the dataset generated from these simulations. The model learns the complex, nonlinear relationships between booth arrangements, obstacle configurations, and the resulting crowd-flow metrics. By capturing these behavioral patterns statistically, the neural network effectively operates as a surrogate simulation engine, predicting outcomes that would normally require time-consuming agent-based computation.
